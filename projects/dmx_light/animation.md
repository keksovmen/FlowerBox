# Документация по управлению DMX-аномалиями через JSON

## 1. Общее описание

Система позволяет задавать динамические анимации для DMX-каналов с помощью JSON-файлов.  
Каждая анимация определяется набором значений каналов (`vals`) и временными интервалами (`times`), которые управляют плавными переходами между этими значениями.  
Дополнительно поддерживаются циклы (`repeat`) для повторения определённых участков анимации.

---

## 2. Структура JSON

Корневой объект содержит массив `data`, каждый элемент которого описывает анимацию для одного или нескольких DMX-каналов.

```json
{
  "data": [
    {
      "i": [0, 1, ...],
      "vals": [0, 128, 255, ...],
      "times": [0, 500, 1000, ...],
      "repeat": [ ... ]   // необязательное поле
    },
    ...
  ]
}
```

---

## 3. Параметры анимации

### 3.1. `i` – массив DMX-каналов

- **Тип:** массив целых чисел
- **Диапазон значений:** от 0 до 511 включительно
- **Описание:** Определяет, на какие DMX-каналы будет воздействовать данная анимация. Все каналы из массива управляются синхронно (одни и те же значения `vals` и `times`).
- **Ограничение:** Длина массива ≤ 255.

### 3.2. `vals` – массив значений

- **Тип:** массив целых чисел
- **Диапазон значений:** от 0 до 255 включительно
- **Описание:** Последовательность целевых значений DMX-каналов. Каждый элемент соответствует определённому моменту анимации (см. п. 4).
- **Ограничение:** Длина массива ≤ 255.

### 3.3. `times` – массив длительностей

- **Тип:** массив целых чисел
- **Диапазон значений:** от 0 до 1 310 700 миллисекунд (≈ 21 минута 50 секунд)
- **Описание:** Определяет временные интервалы между значениями из `vals`.
  - **Первый элемент** (`times[0]`) – время удержания первого значения (`vals[0]`) **до начала перехода** ко второму значению.
  - **Последующие элементы** – длительность плавного перехода от предыдущего значения к текущему.
- **Ограничение:** Длина массива должна совпадать с длиной `vals`. Длина ≤ 255.

### 3.4. `repeat` – массив циклов (необязательно)

- **Тип:** массив объектов
- **Описание:** Позволяет повторять отдельные участки анимации. Каждый объект описывает один цикл.
- **Структура объекта цикла:**
  ```json
  { "f": from_index, "t": to_index, "c": count }
  ```
  - `f` (from) – индекс элемента в `vals`, с которого начинается цикл.
    - Диапазон: от 0 до `vals.length - 2` (нельзя начинать с последнего элемента).
  - `t` (to) – индекс элемента, на который нужно перейти после завершения цикла.
    - Диапазон: от 0 до `vals.length - 1`.
  - `c` (count) – количество повторений цикла.
    - `-1` – бесконечный цикл.
    - `>1` – число повторений (2, 3, …). Значение `1` эквивалентно отсутствию цикла.
    - Максимальное значение: 32767.

---

## 4. Логика работы анимации

Анимация обрабатывает массивы `vals` и `times` последовательно, начиная с индекса `0`.  
Воспроизведение происходит по следующим правилам:

1. **Первый шаг:**  
   Канал устанавливается в значение `vals[0]` и удерживается в течение `times[0]` миллисекунд.

2. **Последующие шаги:**  
   Для каждого следующего индекса `i` (от 1 до `n-1`, где `n` – длина массивов) выполняется плавный переход от предыдущего значения `vals[i-1]` к текущему `vals[i]` за время `times[i]` миллисекунд.

3. **Завершение анимации:**  
   После обработки всех элементов массивов канал остаётся в последнем достигнутом значении (`vals[n-1]`).

4. **Постоянное значение:**  
   Чтобы канал постоянно держал одно значение, достаточно указать массивы длины 1:  
   ```json
   { "i": [42], "vals": [128], "times": [0] }
   ```

## 5. Циклы (`repeat`)

Циклы позволяют повторять определённые фрагменты анимации, не дублируя данные.  
Механизм работы:

- Анимация воспроизводится последовательно, начиная с индекса `0`.
- После завершения обработки **элемента с индексом `k`** система проверяет, есть ли среди объектов `repeat` такой, у которого `f == k`.
- Если такой цикл найден, то:
  - Текущий индекс изменяется на значение `t` из этого цикла.
  - Счётчик повторений цикла увеличивается.
  - Если `c == -1`, цикл повторяется бесконечно.
  - Если `c > 1`, то после `c` повторений (включая первое вхождение) цикл прекращается, и анимация продолжается с индекса, следующего за исходным `f` (т.е. `f+1`), либо завершается, если `f` был последним элементом.
- Если на одном индексе определено несколько циклов, используется первый подходящий (порядок в массиве `repeat` важен).

**Важно:**  
- Цикл может ссылаться на любой индекс, в том числе на тот, который сам находится внутри другого цикла.
- Бесконечный цикл делает невозможным выход из него, если только он не прерывается другим циклом или завершением анимации.

## 6.1 Пример с пояснениями

Рассмотрим фрагмент из предоставленного примера:

```json
{
  "i": [1, 2, 3],
  "vals": [0, 255, 0, 0, 255, 255, 0, 0, 128, 128, 0],
  "times": [0, 1000, 1000, 4000, 0, 125, 0, 125, 1000, 1000, 1000],
  "repeat": [{ "f": 7, "t": 4, "c": 4 }]
}
```

- **`i`:** каналы 1, 2 и 3 управляются одновременно.
- **`vals`:** 11 значений.
- **`times`:** 11 длительностей.
- **Интерпретация:**
  - Индекс 0: значение 0 удерживается 0 мс (мгновенно).
  - Индекс 1: переход от 0 к 255 за 1000 мс.
  - Индекс 2: переход от 255 к 0 за 1000 мс.
  - Индекс 3: переход от 0 к 0 (никакого изменения) за 4000 мс.
  - Индекс 4: переход от 0 к 255 за 0 мс (мгновенно).
  - Индекс 5: переход от 255 к 255 за 125 мс (удержание 125 мс).
  - Индекс 6: переход от 255 к 0 за 0 мс.
  - Индекс 7: переход от 0 к 0 за 125 мс.
  - Индекс 8: переход от 0 к 128 за 1000 мс.
  - Индекс 9: переход от 128 к 128 за 1000 мс.
  - Индекс 10: переход от 128 к 0 за 1000 мс.
- **Цикл:** при достижении индекса 7 (`f=7`) происходит переход на индекс 4 (`t=4`) и повторение этого цикла 4 раза (`c=4`).  
  Фактически участок с индексами 4–7 повторяется 4 раза, затем анимация продолжается с индекса 8.

---

## 6.2 Пример простого градиента

Рассмотрим фрагмент из предоставленного примера:

```json
{
  "i": [1],
  "vals": [128, 255, 128],
  "times": [0, 1000, 1000],
  "repeat": [{ "f": 2, "t": 1, "c": 4 }]
}
```

- **`i`:** канал 1
- **`vals`:** 3 значений.
- **`times`:** 3 длительностей.
- **Интерпретация:**
  - Индекс 0: значение 128 удерживается 0 мс (мгновенно).
  - Индекс 1: переход от 128 к 255 за 1000 мс.
  - Индекс 2: переход от 255 к 128 за 1000 мс.
- **Цикл:** при достижении индекса 2 (`f=2`) происходит переход на индекс 1 (`t=1`) и повторение этого цикла 4 раза (`c=4`).  
  Фактически участок с индексами 1–2 повторяется 4 раза, затем анимация завершается.

---

## 7. Валидация и ограничения

При разборе JSON необходимо проверять:

- Наличие корневого поля `data` (массив).
- В каждом объекте `data`:
  - Поля `i`, `vals`, `times` – массивы одинаковой длины (≤ 255).
  - Все значения `i` в диапазоне 0…511.
  - Все значения `vals` в диапазоне 0…255.
  - Все значения `times` в диапазоне 0…1310700.
  - Если поле `repeat` присутствует – оно должно быть массивом.
    - Каждый объект цикла содержит `f`, `t`, `c`.
    - `f` от 0 до `vals.length - 2`.
    - `t` от 0 до `vals.length - 1`.
    - `c` равно -1 или ≥ 2.
- При обнаружении ошибок (выход за диапазоны, несоответствие длин, неверные типы) анимация для данного объекта не запускается или система переходит к следующему объекту (зависит от реализации).

---

## 8. Заключение

Данный формат позволяет гибко создавать сложные DMX-сценарии с плавными переходами, повторяющимися фрагментами и одновременным управлением несколькими каналами.  
Соблюдение описанных ограничений гарантирует корректную работу системы.
